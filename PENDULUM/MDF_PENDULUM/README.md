# MODELING OF PENDULUM MULTI-DEGREE-OF-FREEDOM (MDOF) STRUCTURE USING OPENSEES

This repository presents a collection of Python-based OpenSees examples dedicated to the nonlinear dynamic analysis of multi-degree-of-freedom (MDOF) pendulum structures, which are written by Salar Delavar Ghashghaei (Qashqai), ranging from simple single-mass systems to progressively more complex multi-mass and multi-spring configurations that serve as simplified models for structural dynamics, seismic response, and vibration control applications such as tuned mass dampers. The scripts implement both elastic and hysteretic inelastic spring behavior, apply artificial or harmonic ground accelerations through equivalent inertial loading, perform Newmark time-history integration with Newton-Raphson iteration, incorporate Rayleigh damping, and evaluate key response quantities including inertia, damping and restoring forces, modal periods with elongation due to inelasticity, logarithmic-decrement damping ratios, force-displacement hysteresis, stiffness degradation, and energy dissipation, while providing comprehensive post-processing through time-history plots, backbone curves, eigenvalue analysis, and supporting utility functions for educational, verification, and parametric studies in earthquake engineering.
