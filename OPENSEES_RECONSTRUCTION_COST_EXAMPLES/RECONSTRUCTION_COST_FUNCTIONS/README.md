**RECONSTRUCTION_COST_DI_FUN** and **RECONSTRUCTION_COST_EDCI_FUN** estimate post-earthquake reconstruction costs for structural models analyzed in OpenSees. The first function computes a Damage Index (DI) from peak absolute displacement relative to yield and ultimate displacements, clamps the result between 0–100 %, classifies the structure into one of eleven damage zones (from “No Damage” to “Failure”), and returns the reconstruction cost as the corresponding percentage of a user-supplied reference cost. The second function evaluates a Dissipated Energy Capacity Index (DECI) by calculating the hysteretic energy dissipated under seismic loading versus that under cyclic pushover (via the shoelace formula, with optional convex-hull alternative and plotting), normalizes the ratio to a 0–100 % index, applies the same eleven-zone classification, and likewise returns the proportional reconstruction cost.
