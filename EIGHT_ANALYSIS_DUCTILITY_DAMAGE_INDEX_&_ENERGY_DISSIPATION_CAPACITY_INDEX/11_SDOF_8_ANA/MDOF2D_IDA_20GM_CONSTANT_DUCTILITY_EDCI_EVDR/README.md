# INCREMENTAL DYNAMIC ANALYSIS (IDA) OF A 2-DOF (X & Y SPRINGS) SYSTEM UNDER 20 GROUND MOTIONS (EACH SCALED AND APPLIED IN X AND Y) WITH CONSTANT DUCTILITY CAPACITY


This script runs an Incremental Dynamic Analysis on a 2-DOF OpenSeesPy structure (`-ndm 2 -ndf 2`): a fixed base node and a mass node (200 t) joined by one `zeroLength` element holding an independent hysteretic spring and viscous damper in X and in Y. The springs differ (X: FY = 6.5 MN, Ke = 350 MN/m; Y: FY = 8.5 MN, Ke = 450 MN/m), so the elastic periods are about 0.150 s in X and 0.132 s in Y. The ductility is constant at 10, so each spring's ultimate displacement is `DSU = DUCT * DY` (about 0.186 m in X and 0.189 m in Y), and the damping ratio is fixed at 3%. It first runs a cyclic displacement protocol (amplitude DSU) on each spring, once, to get the baseline dissipated energy. It then loops over 20 ground-motion pairs (record g in X and record g + 1, wrapping around, in Y). Each pair is scaled in 20 equal steps of intensity IM, the geometric-mean PGA of the pair, from 0.05 g to 2 g. At each level both components are applied together in a nonlinear Newmark time-history analysis. For each direction it stores the peak displacement, velocity, acceleration and base reaction, the damage index, the stiffness, the damping ratio from logarithmic decrement, the Energy Dissipation Capacity Index (EDCI) and the equivalent viscous damping ratio (EVDR). A pair counts as collapsed when the peak displacement reaches DSU in X or Y, or when the analysis fails to converge, and it is then not scaled further, so its remaining levels are NaN. The results are saved to Excel and plotted as IDA curves, one color per record, with a mean ± std band and median and 16/84% fractile curves. Collapse points are marked on the curves. Collapse and damage-state fragility curves come from lognormal fits of the IM at which each record reaches collapse or a damage-index threshold of 20, 40, 60 and 100%. The script then pools all valid points for histograms, scatter and cluster plots, random forest, a correlation heatmap and regression, and ends with hysteresis loops, time histories and an X-Y orbit for the last run. One small thing: the comment above `PLOT_IDA` still says "EDP on the horizontal axis", but the function now puts IM on the horizontal axis.
