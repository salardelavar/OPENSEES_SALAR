# PARAMETRIC NONLINEAR SEISMIC DEMAND SPECTRA OF SDOF SYSTEMS WITH VARIABLE DUCTILITY CAPACITY IN OPENSEES
# طیف‌های تقاضای لرزه‌ای غیرخطی پارامتریک سیستم‌های یک‌درجه‌آزادی با ظرفیت شکل‌پذیری متغیر در اوپنسیس



This Python/OpenSeesPy script performs a parametric nonlinear time-history analysis of single-degree-of-freedom (SDOF) systems with constant yield strength and variable ductility capacity, first running a cyclic displacement protocol to establish a baseline dissipated energy capacity, then subjecting the same system to a selected ground motion while sweeping mass (and therefore period) to generate inelastic response spectra for displacement, velocity, acceleration, base reaction, ductility damage index, stiffness, damping ratio, energy dissipation capacity index, and equivalent viscous damping ratio; it computes damage and energy-based metrics, exports the peak response data to Excel, visualizes spectra with statistical summaries (mean, median, quartiles, standard deviation), performs fragility and machine-learning/correlation analyses, and plots time histories and hysteresis loops. Note, however, that despite the original header calling it a “constant ductility” response spectrum, the code does not iteratively scale the ground motion to enforce a target ductility demand; instead, it varies the ductility capacity of the backbone curve while keeping the seismic intensity and yield strength fixed, so it is more accurately described as a parametric nonlinear seismic demand spectrum study with variable ductility capacity.
