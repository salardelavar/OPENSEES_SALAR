# ELASTIC vs. INELASTIC RESPONSE SPECTRA (BASE REACTION, DISPLACEMENT, VELOCITY, ACCELERATION) OF A NONLINEAR HYSTERETIC MDOF SHEAR BUILDING UNDER GROUND MOTION (FINITE ELEMENT METHOD IN PYTHON AND OPENSEESPY VERIFICATIONS)

# طیف‌های پاسخ الاستیک در برابر غیرالاستیک (واکنش پایه، جابجایی، سرعت و شتاب) یک ساختمان برشی چنددرجه‌آزادی با رفتار هیسترتیک غیرخطی تحت تحریک زلزله (روش المان محدود در پایتون و صحت‌سنجی با OpenSeesPy)


This Python script implements a verification framework for the elastic and inelastic seismic response of an N-story shear building (one lateral degree of freedom per floor) under recorded ground motion, comparing a custom pure-Python Newmark-average-acceleration + Newton-Raphson solver against OpenSeesPy (zeroLength elements with Elastic or HystereticSM materials, UniformExcitation, and Newmark integrator). It first builds the structural model by assembling the initial stiffness matrix from story stiffnesses (auto-scaled so the fundamental period equals a prescribed T1 when stiffnesses are not supplied), assigns story yield shears proportional to the mass above each story via a constant yield coefficient Cy, constructs identical multi-linear peak-oriented hysteretic backbones for every story, and forms Rayleigh damping matched to the first two modes; the custom integrator then solves the residual force equilibrium at each time step with a consistent tangent, while the OpenSees counterpart recovers failed steps by trying alternative convergence tests and algorithms. From the resulting time histories the script extracts peak absolute accelerations (PGA), relative velocities (PGV) and displacements (PGD), story shears (base reaction = story-1 shear) and inter-story drifts, computes both elastic and inelastic ground-motion response spectra (base-shear coefficient, Sd, Sv, Sa) with the same backbone rule, and evaluates linear floor spectra driven by the absolute accelerations of every floor of the inelastic building; finally it generates multi-panel comparison plots of story profiles, time histories, hysteresis loops, ground spectra and floor spectra, together with quantitative relative-error statistics between the two solvers, thereby demonstrating that the independent numerical implementation reproduces OpenSeesPy results to high accuracy for both elastic and inelastic regimes.
