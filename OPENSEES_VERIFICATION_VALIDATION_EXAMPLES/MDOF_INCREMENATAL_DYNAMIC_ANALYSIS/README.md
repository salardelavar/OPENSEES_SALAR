# INCREMENTAL DYNAMIC ANALYSIS (IDA) OF A MULTI NONLINEAR SHEAR BUILDING

This script runs an incremental dynamic analysis of your 10-story nonlinear shear building under 200 ground motions. The top section defines the settings: record file pattern, time step, intensity levels G (0.1g to 3.0g), PGA normalization, the drift-based collapse limit, solver tolerances, and the backbone (yield, peak and two residual points) plus mass, damping and T1 = 1 s. BUILD_PARAMS computes the floor mass and Rayleigh coefficients once, using your MDOF_DYNAMIC_TIME_HISTORY functions, so every worker uses the identical structure. RUN_ONE_LEVEL is the core: it builds the OpenSeesPy model (a fixed ground node, floor masses, and zero-length HystereticSM story springs), applies one scaled record as uniform base excitation, steps through it with Newmark and Newton iterations, and keeps only the running peaks of roof displacement, velocity, absolute acceleration and base reaction. If a step fails, RECOVER_STEP tries other algorithms. If that also fails, or a story drift exceeds DRIFT_LIMIT, the run stops and is flagged as collapsed. RUN_RECORD takes one ground motion, normalizes it if requested, and runs it through all intensity levels in increasing order. After the first collapse it skips the higher levels and copies the collapse values into them. Each record’s results are saved to IDA_RESULTS/IDA_k.npy, so an interrupted run can resume. In the main block, a ProcessPoolExecutor runs the 200 records in parallel and prints progress as each finishes. The results are then assembled into the DATA dictionary (1 = displacement, 2 = velocity, 3 = acceleration, 4 = base reaction) and the COLLAPSE array, and saved to IDA_DATA.npz. The collapse fraction per level is printed, and the plots come last.
