# EXPERIMENTALLY VALIDATED CYCLIC ANALYSIS OF AN RC CANTILEVER COLUMN USING A LUMPED PLASTICITY MODEL IN OPENSEESPY

This Python script implements a nonlinear cyclic analysis of a 200 × 200 mm reinforced concrete cantilever column with a height of 750 mm in OpenSeesPy, using a lumped plasticity approach with a zero-length rotational plastic hinge at the column base and an elastic Timoshenko beam element for the remaining column length. The plastic hinge moment–rotation backbone is derived directly from a moment–curvature analysis of a fiber-based reinforced concrete section under a constant axial gravity load of 156 kN, incorporating Mander's confined concrete model, Concrete02 for confined and unconfined concrete, and Steel02 for longitudinal reinforcement. The effective flexural stiffness is calculated from the section yield moment and curvature, while the Ibarra–Krawinkler stiffness formulation is used to distribute the effective stiffness between the elastic column element and the rotational hinge spring. The resulting moment–rotation relationship is implemented using the Hysteretic material, with pinching parameters to represent cyclic degradation characteristics. The model then performs displacement-controlled cyclic loading using multiple loading amplitudes, accounting for geometric nonlinearities through a Corotational transformation and monitoring the column's lateral displacement, base shear, axial force, base moment, and plastic hinge rotation. Finally, the numerical hysteresis response is compared with experimental data imported from an Excel file, using performance indicators such as peak shear strength, secant stiffness, envelope RMSE, and cumulative work, while generating graphical representations of the hysteretic response, backbone curves, moment–rotation relationship, axial response, and numerical-to-experimental comparison.
