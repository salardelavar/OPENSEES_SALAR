# RESONANCE OF A MULTI-STORY SHEAR BUILDING: ELASTIC vs. INELASTIC  (FINITE ELEMENT METHOD IN PYTHON AND OPENSEESPY VERIFICATIONS)

This Python script performs nonlinear time-history analysis of an N-story shear building under resonant harmonic ground motion, comparing purely elastic story springs against peak-oriented hysteretic (inelastic) springs. It assembles the initial elastic stiffness and mass matrices, extracts modal properties (including the fundamental frequency used to set the excitation frequency for resonance), applies Rayleigh damping, and integrates the equations of motion with the average-acceleration Newmark-β method plus Newton–Raphson iteration at each step; an equivalent OpenSeesPy model (zero-length elements with Elastic or HystereticSM materials, UniformExcitation, and the same Newmark integrator) is run for verification. The script also supplies a closed-form elastic mode-1 resonance envelope, generates frequency-response (sweep) curves of peak roof displacement versus excitation-to-natural-frequency ratio, and produces diagnostic plots of ground acceleration, roof displacement histories, hysteresis loops, peak-drift profiles, and the resonance curves, thereby illustrating how yielding elongates the period, detunes the structure from the forcing frequency, and limits the response relative to the continuously growing elastic resonant amplitude.
