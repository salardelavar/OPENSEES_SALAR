# NONLINEAR DYNAMIC (TIME-HISTORY) ANALYSIS OF PARALLEL NONLINEAR SDOF SPRINGS (FINITE ELEMENT METHOD IN PYTHON AND OPENSEESPY VERIFICATIONS)

This script runs a nonlinear time-history analysis of a single-degree-of-freedom system, made of five parallel hysteretic springs that share one multilinear backbone, and checks a hand-written solver against OpenSeesPy. The system obeys `m·u'' + c·u' + Fs(u) = −m·ag(t)`, with mass chosen for a 0.5 s initial period, 5% mass-proportional damping, and the scaled ground acceleration record as excitation. In the numerical solver, `SDOF_NUMERICAL_DYNAMIC_NEWMARK` marches through the record with Newmark-β (average acceleration). At each step it guesses the displacement, computes the implied acceleration and velocity, and calls `SPRING` to get the spring force. It then forms the dynamic residual and corrects the displacement with Newton-Raphson, using the effective tangent `k + γc/(βΔt) + m/(βΔt²)`, until the normalized residual drops below the tolerance. `SPRING` is a pure function of the committed state and the trial displacement, so iterating never corrupts the history. It stores the last reversal point, the largest peaks on each side and the start of the last unloading, mirrors the motion so it always looks like it goes toward +x, and picks a branch. The branches are the backbone beyond the previous peak, unloading along k₀, retracing k₀ after a partial unloading, or reloading toward the previous peak. Once a step converges, the state is committed. The solver returns time, displacement, velocity, acceleration, force with the sign flipped to match OpenSees' reaction convention, iteration counts and residuals. `SDOF_OPENSEES_DYNAMIC` builds the same system with `HystereticSM` zeroLength springs, a nodal mass, `rayleigh` damping equal to `2ξω₀m`, a `Path` time series with `UniformExcitation`, and a Newton/Newmark `Transient` analysis. It falls back on the `ANALYSIS` helper's alternative tests and algorithms if a step fails. The main block defines the backbone and the record, runs both solvers, prints the maximum absolute and relative errors in displacement and force, and plots the ground motion, displacement history, hysteresis loops and absolute acceleration. The two solvers agree to roundoff, which confirms that the hysteresis rule and the Newmark-Newton scheme reproduce OpenSees.
